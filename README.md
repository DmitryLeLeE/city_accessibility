# City Accessibility

Веб-приложение для анализа **пешей доступности городской инфраструктуры** в любом городе мира. Работает целиком в браузере на открытых данных [OpenStreetMap](https://www.openstreetmap.org): ни сервера, ни ключей API, ни регистрации.

## Что умеет

| Возможность | Как это работает |
|---|---|
| **Изохроны 5 / 10 / 15 минут** | Клик по карте → кратчайшие пешие пути по сети улиц и троп (алгоритм Дейкстры) → контуры зон. Значения минут и скорость пешехода настраиваются. |
| **Доступность больниц, школ, парков** | Для каждой зоны считается число объектов и время до ближайшего. Дополнительно: аптеки, детские сады, продуктовые магазины, остановки транспорта (список категорий — в `js/config.js`). |
| **Анализ пешеходной сети** | Граф строится из путей OSM (`highway=*`, без автомагистралей и закрытых проходов), рёбра делятся на отрезки ≤ 40 м, лестницы штрафуются, мелкие изолированные «острова» сети отбрасываются. |
| **Поиск проблемных районов** | Видимая область разбивается на ячейки 150 м; связные группы ячеек с индексом доступности ниже 35 объединяются в нумерованные **проблемные зоны** с указанием, чего им не хватает больше всего. |
| **Сравнение районов** | Административные границы из OSM (`admin_level`, определяется автоматически) или квадратная сетка 500 м – 2 км. Таблица с сортировкой: индекс, доля жителей в зоне ≤ 15 мин и медиана времени по каждой категории. Экспорт в CSV и GeoJSON. |

## Быстрый старт

```bash
git clone https://github.com/DmitryLeLeE/city_accessibility
cd city_accessibility
npm start            # python3 -m http.server 8080 → http://localhost:8080
```

Сборка не нужна: это статические файлы и ES-модули. Открывать `index.html` напрямую (`file://`) нельзя — модули требуют HTTP.

**Публикация на GitHub Pages:** Settings → Pages → Source: *GitHub Actions*. Workflow `.github/workflows/pages.yml` сначала запускает тесты, затем выкладывает сайт.

## Как пользоваться

1. Найдите город в поиске слева или просто сместите карту.
2. **Изохроны из точки:** кликните по карте. Маркер можно перетаскивать, зоны пересчитываются.
3. **Анализ города:** наведите карту на нужный участок и нажмите «Рассчитать для видимой области». Область анализа — видимая часть карты, но не больше 8 × 8 км (`maxAnalysisSpanKm`); для большого города анализируйте его по частям. Загруженные фрагменты данных кэшируются на время сессии.

## Методика

- **Время** = длина пути × штраф за тип (лестницы ×1.5) / скорость. Скорость по умолчанию 4,8 км/ч.
- **Привязка объектов к сети** — к ближайшему узлу графа не дальше 150 м (здания — 200 м, стартовая точка — 300 м); расстояние привязки включается во время пути. Парки считаются доступными с любой точки границы (вход — каждые ~60 м по контуру).
- **Жители.** Реальной численности в OSM нет, поэтому используется прокси: каждое жилое здание весит столько, сколько у него этажей (`building:levels`; квартирные дома без тега — 5, остальные — 1). Режим «По улицам» вместо зданий берёт узлы сети с весом по длине улиц и считается быстрее.
- **Индекс доступности** по категории: 100 баллов при ≤ 5 мин, 0 при ≥ 20 мин, между ними линейно. Итоговый индекс — среднее по выбранным категориям, взвешенное по «жителям». Пороги меняются в `CONFIG.index`.
- **Проблемные зоны:** ячейки 150 м с индексом < 35 и спросом не ниже половины медианного, 8-связные группы.
- **Контур изохроны:** достижимые узлы → растр 40 м → расширение на 1 клетку → трассировка границ → сглаживание Чайкина; отверстия меньше 4 га заливаются.

## Структура

```
index.html          разметка
css/style.css       оформление
js/config.js        параметры, категории объектов, палитры
js/geo.js           геометрия (haversine, проекция, point-in-polygon, площади)
js/graph.js         граф пешеходной сети, привязка точек, Дейкстра
js/isochrone.js     построение контуров
js/overpass.js      Overpass/Nominatim: тайлы, кэш, повторы, зеркала
js/analysis.js      индекс, районы, проблемные зоны, экспорт
js/app.js           интерфейс на Leaflet
tests/run.mjs       тесты ядра на синтетической сетке улиц
```

Тесты (`npm install && npm test`) проверяют ядро без сети: длины путей на сетке, площадь и вложенность изохрон, «дырки» в контурах, привязку, индекс, разбор данных OSM.

## Ограничения

- Overpass API — общий бесплатный ресурс. Приложение грузит данные небольшими фрагментами, ограничивает параллелизм и переключается между зеркалами, но при очень частых запросах сервер может ответить ошибкой; подождите и повторите.
- Площадные пешеходные зоны (`highway=pedestrian` + `area=yes`) и проходы через дворы, не нанесённые на карту, в сеть не попадают: качество результата зависит от полноты OSM в конкретном городе.
- Пока учитывается только пешеходное передвижение; рельеф, светофоры и барьеры (заборы, железные дороги без переходов) учитываются лишь настолько, насколько они отражены в сети.
- Административные границы районов бывают нарезаны по-разному; если нужного уровня нет, выберите `admin_level` вручную или режим «Квадраты».

## Идеи для развития

Велосипед и общественный транспорт, учёт рельефа, кэш в IndexedDB, Web Worker для расчётов, загрузка собственных слоёв объектов (GeoJSON), перевод интерфейса.

# Участие в проекте / Contributing

Спасибо за интерес! / Thanks for your interest!

## Быстрый старт

```bash
npm ci
npm test            # юнит-тесты ядра (без браузера и сети)
npm run lint        # ESLint
npm start           # статический сервер: http://localhost:8080
npm run test:e2e    # e2e в браузере (нужен Chromium: npx playwright install chromium
                    # либо CHROME_PATH=/путь/к/chrome)
```

## Правила

* Приложение — статические ES-модули без сборки; сторонние библиотеки лежат в `vendor/`.
* Любое изменение модели (время пешком, перекрёстки, индекс) сопровождайте тестом в `tests/run.mjs` и правкой `docs/METHODOLOGY.md` / `docs/METHODOLOGY.en.md`.
* Новые строки интерфейса пишите по-русски через `_('…')`, английский перевод добавляйте в `js/lang-en.js` — тест локализации проверит покрытие и плейсхолдеры.
* Не добавляйте ключи API, трекеры и запросы к новым внешним сервисам без обсуждения (см. `PRIVACY.md`).
* Перед PR: `npm test && npm run lint && npm run test:e2e`.
* Сообщения коммитов — кратко, по сути; один PR — одна тема.

## Сообщения об ошибках

Приложите: город/координаты, скорость, шаги, и **журнал расчёта** (раскрывающийся блок «Журнал расчёта» в панели) — в нём видно, какие зеркала Overpass отвечали.
